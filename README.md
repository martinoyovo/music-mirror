# Music Mirror

Music Mirror is a mobile-friendly listening insights dashboard for Spotify. It is designed to feel closer to a music health dashboard than a traditional music player.

## Documentation

- [Spotify data model and limitations](docs/SPOTIFY_DATA.md)

## Current Data Caveat

The app currently uses live Spotify Web API data without a database. Recently played data should be treated as an available recent sample, not a complete daily, weekly, or monthly listening archive.
